# Purple Gym – Gym Website Concept

## About the Project
Purple Gym is a modern gym website concept designed and developed as part of my personal web development training and practice.

The main objective of this project is to improve my frontend development skills by creating a professional-looking website for a fitness and gym business.

## Project Highlights
- Modern and attractive UI design
- Stylish typography and color combinations
- Responsive website layout
- Gym-related sections and content
- User-friendly navigation
- Fitness-focused visual presentation

## Design Theme
The website follows a Berry Sport color palette, combining a rich plum background, cream-colored text, and coral accents to create a stylish fitness brand identity.

## Purpose
This project was developed for learning, experimentation, and improving my practical frontend development skills. It is a concept website and is not affiliated with an actual gym business.

## Project Type
Personal Training & Practice Project
